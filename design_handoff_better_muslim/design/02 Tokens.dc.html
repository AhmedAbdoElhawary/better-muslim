TOKENS · MAIN THEME #9 QIYAM EMERALD

Design tokens

Every value the app uses, named so it maps 1:1 to Flutter. Colors come from ColorScheme where Material has a slot, and from the BmColors / BmSky ThemeExtensions where it doesn't. Swapping a theme means swapping one color file; type, space, radius and motion are shared.

Elevation, glass and opacity

Light mode uses soft green-tinted shadows. Dark mode is true black, where shadows are invisible, so depth comes from a lighter surface, a hairline and, for the hero card only, a dim gold glow.

06

Flutter mapping

Token names map directly to code. A theme is one BmThemeData file; switching themes rebuilds MaterialApp.theme with a new ColorScheme and extensions. Everything else reads from BmSpace, BmRadius, BmMotion and Theme.of(context).

// lib/theme/tokens/qiyam_emerald.dart
final qiyamEmeraldDark = BmThemeData(
  brightness: Brightness.dark,
  scheme: const ColorScheme.dark(
    surface: Color(0xFF000000),            // color.bg
    surfaceContainerLow: Color(0xFF07100D), // color.surface
    surfaceContainer: Color(0xFF0C1814),    // color.surfaceRaised
    onSurface: Color(0xFFD9D3C2),           // color.text
    onSurfaceVariant: Color(0xFF878C82),    // color.text2
    primary: Color(0xFFA88A52),
    onPrimary: Color(0xFF000000),
    secondary: Color(0xFF4E9C80),           // color.accent
    error: Color(0xFFE07A6A),
    outlineVariant: Color(0xFF1C2C26),
  ),
  colors: const BmColors(                    // ThemeExtension<BmColors>
    textTertiary: Color(0xFF6C716A),
    glow: Color(0xFFA88A52),
    success: Color(0xFF5FB389),
    warning: Color(0xFFD2A04F),
  ),
  sky: BmSky.qiyamEmerald,                   // ThemeExtension<BmSky>, 6 × 3 stops
);

// Shared, theme-independent
abstract final class BmSpace  { static const s1 = 4.0, s2 = 8.0, s3 = 12.0, s4 = 16.0, s5 = 20.0, s6 = 24.0; }
abstract final class BmRadius { static const sm = 10.0, md = 14.0, lg = 20.0, xl = 28.0; }
abstract final class BmMotion {
  static const micro = Duration(milliseconds: 150), standard = Duration(milliseconds: 300),
               emphasized = Duration(milliseconds: 520), ambient = Duration(seconds: 6);
  static const standardCurve = Cubic(0.2, 0, 0, 1), breathe = Cubic(0.37, 0, 0.63, 1);
  static final needle = SpringDescription.withDampingRatio(mass: 1, stiffness: 120, ratio: 0.55);
}
NamingDesign token color.text2 = Flutter onSurfaceVariant. The full table is in the Color section above.
RTLUse EdgeInsetsDirectional and AlignmentDirectional everywhere. Media controls, clocks and the sun arc are wrapped in Directionality(ltr).
Dynamic typeTextScaler clamped to 2.0. Countdown and prayer row switch to stacked layouts above 1.4.
