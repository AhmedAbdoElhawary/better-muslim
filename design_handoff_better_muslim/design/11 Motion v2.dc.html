Transitions

Twelve patterns cover every navigation and feedback moment in the app. Each card loops; click to replay from the start.

01Push and popRESPONSIVE
520 ms in · 420 ms out · standard

Going deeper. The new screen covers from the trailing edge; the old one moves back 30% and dims. Back reverses at 420 ms. RTL mirrors the direction.

02Swipe backRESPONSIVE
follows finger · release spring.gentle

From the leading edge on every pushed screen. The page tracks the finger 1:1. Past 35% of the width, or a fling above 700 px/s, it completes; otherwise it springs home.

03Fade throughRESPONSIVE
120 ms out · 300 ms in · scale .96 → 1

Between tabs, which are siblings with no spatial relationship. The old page fades out quickly, the new one fades in with a slight zoom. The tab pill slides at the same time.

04Container transformCEREMONIAL
520 ms · standard · radius 20 → 0

A card opens into its own screen: the next prayer card into Prayer, a surah into the reader. The card’s bounds grow to the screen; its content cross-fades in the middle 40%.

05Shared axisRESPONSIVE
300 ms · x 30 px · fade

Steps in a sequence: onboarding, the zakat calculator, a memorisation plan. Forward moves content left and in from the right; back is the reverse.

06List entranceAMBIENT
300 ms each · 30 ms stagger · max 8

The first time a list appears on a screen. Rows rise 12 px and fade in, 30 ms apart. Rows past the eighth appear with the eighth, so no list waits more than 210 ms.

07Skeleton to contentAMBIENT
shimmer 1200 ms · crossfade 150 ms

Lists and cards load into skeletons of their final shape, never a spinner. Content replaces the skeleton in one 150 ms crossfade, with no layout shift.

08DialogRESPONSIVE
300 ms in · decelerate · 150 ms out

Confirmations only: delete a note, reset a count. Scales from 94% with a fade so it reads as raised in place. Dismissal is a plain 150 ms fade.

09Mode changeCEREMONIAL
520 ms · sacred · reveal from the control

Dark to light, a theme pick, or the sky switching to light at sunrise. The new palette opens as a circle from the control that changed it. Automatic changes open from the sun’s position.

10ToastRESPONSIVE
in spring.snappy · hold 1800 ms · out 220 ms

Saved, recorded, copied. Drops from under the status bar and springs into place. One at a time; a new toast replaces the old one without the exit.

03

Rules

How loading and transitions behave across the whole app.

Wait before showing
No loader for the first 400 ms. Most loads finish sooner, and a loader that flashes for 100 ms reads as a glitch.
Stay once shown
A loader that appears stays at least 600 ms, ending on a completed ripple, never mid-fall.
One at a time
One oil drop on screen. Lists use skeletons; buttons use the inline size.
Interruptible
Every transition can be reversed mid-flight. It retargets from its current value and velocity; nothing waits for an animation to end.
Direction
Push, swipe back and shared axis mirror in Arabic. The oil drop, the sun and the mode reveal do not.
Nothing during prayer
While the adhan plays or a prayer is being marked, ambient motion stops and only the ceremonial animation for that moment runs.
Budget
Transitions animate transform and opacity only, except the container’s bounds. Each screen is wrapped in a RepaintBoundary; the loader repaints only its own layer.

Flutter

Container transform, fade through and shared axis come from the animations package with the app’s durations and curves. The loader and the push route are custom.

class BmOilDrop extends StatefulWidget {
  const BmOilDrop({super.key, this.size = 48, this.progress});
  final double size;
  final double? progress; // null = loop; 0..1 = pool level

  @override
  State<BmOilDrop> createState() => _BmOilDropState();
}

class _BmOilDropState extends State<BmOilDrop> with TickerProviderStateMixin {
  late final _loop = AnimationController(vsync: this, duration: BmMotion.oilCycle)..repeat(); // 1600 ms
  late final _level = AnimationController.unbounded(vsync: this, value: widget.progress ?? .43);

  @override
  void didUpdateWidget(BmOilDrop old) {
    super.didUpdateWidget(old);
    final p = widget.progress;
    if (p != null && p != old.progress) {
      _level.animateWith(SpringSimulation(BmMotion.gentle, _level.value, p, _level.velocity));
    }
  }

  @override
  Widget build(BuildContext context) {
    final reduce = BmMotion.reduce(context);
    return Semantics(
      label: context.l10n.loading,
      value: widget.progress == null ? null : '${(widget.progress! * 100).round()}%',
      child: RepaintBoundary(
        child: CustomPaint(
          size: Size.square(widget.size),
          painter: BmOilDropPainter(
            loop: _loop, level: _level,
            showDrop: widget.size >= 32 && !reduce,
            colors: BmOilColors.of(context), // star = primary, oil = #D9BE86 → #8C7444, sun = BmSky.sun
          ),
        ),
      ),
    );
  }
}
