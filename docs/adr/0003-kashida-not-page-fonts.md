# Kashida, not the QCF page fonts

Partly replaced by 0004: the QCF page fonts came back as downloaded Mushaf styles, kashida stays for Text.

A mushaf line is as wide as the print's, but the words in KFGQPC Hafs are narrower than the print's, so the leftover width went into the gaps: half the lines had gaps over twice a space, the worst almost nine. The QCF V2 page fonts would draw every line exactly like the print, but they are 604 font files of unknown size, they make the font choice in Display meaningless and they need their own asset pipeline. So the page draws kashidas instead, like a calligrapher: gaps stop at one and a half spaces and the rest of the width goes into the joining strokes. The kashidas exist only in the painted page, never in the text that is copied, shared or searched.
