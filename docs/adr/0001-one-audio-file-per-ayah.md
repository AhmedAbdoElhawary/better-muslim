# One audio file per ayah, not one per surah

Recitation plays one EveryAyah file per ayah. Whole-surah files with ayah timings would give a real time bar, but they mean a new source and a rewrite of the player, repeat, range and follow. Per ayah, the reciters stay on one source, a downloaded surah is just its ayah files, and each ayah repeats with no gap. So the progress bar counts ayahs, not minutes. Dragging it picks an ayah, and ±10 s moves through the audio, crossing into the next or previous ayah.
