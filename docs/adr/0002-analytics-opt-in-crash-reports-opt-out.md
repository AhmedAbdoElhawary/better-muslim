# Analytics is opt-in, crash reports are opt-out

Just using this app can say something about someone's religion, so Firebase Analytics stays off until the person says yes, and a switch in More turns it off again. That gives less data than on by default, and I accept that. Sentry stays on by default with its own switch in More, it carries no PII and an opt-in would miss a crash on first launch. Either way the app never sends location, city, the prayer log, qada, notes, bookmarks, highlights, tasbih counts or what someone reads. Only screens, feature names and technical errors leave the phone.
