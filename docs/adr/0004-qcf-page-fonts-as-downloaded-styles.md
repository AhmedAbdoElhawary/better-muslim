# QCF page fonts as downloaded Mushaf styles

Partly replaces 0003. Kashida stays for Text, the default Mushaf style, which is on the phone and works offline. QCF V2, V4 Tajweed and V1 come next to it as styles I pick in Display and download once, one gzipped file each from the content repo's releases (about 140, 70 and 55 MB), because all 604 page fonts are too big to ship and Flutter can't read woff2. They draw the mushaf page and, since specs/018, the translation layout's cells too, in the glyphs of the pages the ayah is on. The share card, copy and search keep the Unicode text and the Font choice. V1 gets the 1405H print's own pages, where 56 ayahs sit on another page than in 1421H, so its page numbers are its own, while the database keeps 1421H page numbers and maps through the page's first ayah. V4's colors come from its own palettes, picked per page color by rewriting the font's palette as it loads, since Flutter can't choose one.
