# Add note field

**What to build:** an ayah with no note shows Add note in the Study sheet's Notes tab, the real field comes only on a tap.

**Status:** done

- [x] With no note, a gray box the size of the field says Add note under the Note label. No Highlight, no Save.
- [x] A tap swaps it for the field with the keyboard, Highlight on and Save under it.
- [x] A note, even a highlight with no text, opens straight into the field with Delete note.
- [x] It stays open without typing, it closes again on another ayah, a new sheet or a delete.
- [x] The field grows from its 52 to 300 pt, then scrolls inside.
- [x] Saved's Notes and Highlights cards stop the note text at 300 pt and scroll it, a short note leaves the drag to the list.
