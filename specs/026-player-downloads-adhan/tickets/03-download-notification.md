# Download notification

**What to build:** an Android notification with a progress bar for every download I start.

**Status:** done

- [x] A data sync foreground service holds it while a download runs.
- [x] Mushaf styles, tafsirs, a reciter's surah, adhan recordings.
- [x] Pops up once, updates quietly with the bar, percent and MB.
- [x] Pause, Resume and Cancel. Resume goes on from the part.
- [x] Done removes it, failed leaves a "Couldn't download" one.
