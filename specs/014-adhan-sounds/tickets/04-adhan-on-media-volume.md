# 04: The adhan on the media volume

**What to build:** The Android Full adhan plays on the media volume, so the volume keys change it.

**Blocked by:** None (can start immediately)

**Status:** waiting for a run on the phone

- [x] `AdhanService` plays and asks for audio focus with `USAGE_MEDIA`.
- [ ] On the phone the volume keys change the adhan as it plays, also with the screen off.
